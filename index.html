Sobre

Trabalho na fronteira entre implementação e design. No Só+1, um SaaS real de organização de futebol amador, contribuo dos dois lados do produto: na API (Express 5, Prisma, PostgreSQL, Stripe) e no front-end (React 19, Vite, SSE). No SIDAGRO, sistema governamental do Instituto Mineiro de Agropecuária, desenvolvo o front-end — e também atuo como UX/UI Designer no mesmo projeto, desenhando as telas que depois implemento.

Essa dupla atuação não é acidental: entender a interface me faz escrever código mais alinhado ao que o usuário precisa, e entender o código me faz desenhar interfaces que são possíveis de construir. Já liderei o design de sistemas para a UFLA (NEMASA) e coordenei, de ponta a ponta, o redesign de uma plataforma EdTech. Uso IA generativa como parte real do processo — para ideação, prototipação e para acelerar o caminho entre uma ideia e código em produção.
