02 · IA por voz

Alexa AI Bridge

Papel: criei a integração e cuidei da implementação na AWS.

Pessoa + Echo
→
Alexa Skill
→
AWS Lambda
→
OpenAI + web

Problema e contexto

A resposta precisava funcionar bem por voz

A Alexa recebe perguntas abertas, consulta a OpenAI e fala a resposta. Isso exige informação atual e um texto curto o bastante para ser entendido sem uma tela.

Processo e decisões

A conversa fica somente na sessão

  • A Responses API sempre consulta a web.
  • previous_response_id mantém o contexto enquanto a sessão está aberta.
  • Os nomes das fontes são ajustados para soar melhor na fala.

Restrições técnicas

A Alexa não pode ficar esperando

A Lambda tem um limite total de 7,2 segundos. Desativei novas tentativas automáticas e classifiquei os erros para facilitar o diagnóstico sem falar detalhes técnicos ao usuário.

Como validei

Os caminhos principais têm testes

Os testes cobrem respostas, contexto, pesquisa web, timeout e falhas.

  • 15testes automatizados aprovados*
  • 7,2sprazo total definido
  • 1 sessãolimite do contexto

*Pytest executado localmente em 15/09/2026: 15 testes aprovados.

02 · Voice AI

Alexa AI Bridge

Role: I built the integration and handled its AWS implementation.

Person + Echo
→
Alexa Skill
→
AWS Lambda
→
OpenAI + web

Problem and context

The answer had to work well by voice

Alexa receives open-ended questions, checks with OpenAI, and speaks the answer. That requires current information and text short enough to understand without a screen.

Process and decisions

The conversation stays within the session

  • The Responses API always searches the web.
  • previous_response_id keeps context while the session is open.
  • Source names are adjusted to sound better when spoken.

Technical constraints

Alexa cannot keep the user waiting

The Lambda has a 7.2-second overall deadline. I disabled automatic retries and classified errors so failures are easier to diagnose without reading technical details to the user.

How I validated it

The main paths have automated tests

Tests cover responses, context, web search, timeouts, and failure paths.

  • 15automated tests passing*
  • 7.2stotal deadline
  • 1 sessioncontext boundary

*Pytest run locally on September 15, 2026: 15 tests passed.
